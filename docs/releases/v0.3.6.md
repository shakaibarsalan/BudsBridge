The build isn't code-signed yet, so SmartScreen warns once: **More info → Run anyway**. Where Smart
App Control is on, Windows blocks unsigned apps completely.

### Code signing is on its way

BudsBridge is applying for free code signing from SignPath Foundation. The release workflow is
ready for it: it now signs the program first, builds the installer around the signed copy, then
signs the installer, as soon as the project is accepted. See the code signing policy in the README.

### Updating

Opening the new `BudsBridge.exe` while 0.3.1 or newer runs switches to the new one by itself.

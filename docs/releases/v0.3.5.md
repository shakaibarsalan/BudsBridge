**BudsBridge's logo in the installer.** The setup file now has the BudsBridge icon instead of the
generic installer one, and the installer's pages show the logo too.

### Download

| File | What it is |
|---|---|
| `BudsBridge.exe` | Single file, no installer. Download and open it |
| `BudsBridge-0.3.5-windows-x64-setup.exe` | Installer for your user only: Start menu entry and uninstaller, no admin prompt |
| `SHA256SUMS.txt` | Checksums for both files |

The build isn't code-signed yet, so SmartScreen warns once: **More info → Run anyway**. On a PC with
Smart App Control turned on, Windows blocks unsigned apps completely; code signing is planned.

### Changed

- When Windows' Bluetooth driver fails to start a phone's audio (error `0x8007001f`), the message
  now says what to try: turn Bluetooth off and on, on the laptop and on the phone. It used to
  suggest the phone might never work, which isn't true: it was seen with a phone that had worked.

### Updating

Opening the new `BudsBridge.exe` while 0.3.1 or newer runs switches to the new one by itself.

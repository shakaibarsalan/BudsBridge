**The dock, now as the latest release.** Click the BudsBridge icon in the tray and a small panel
opens beside it: a live picture of phone → laptop → buds, how many sound sources reach your buds,
tiles that switch the buds and phone audio, and the device and phone lists. The full window only
opens for settings.

Bridge mode has worked on a real Windows 11 laptop with an OPPO A83 and TWS buds. The rest of the
[hardware checklist](https://github.com/shakaibarsalan/BudsBridge/blob/main/docs/HARDWARE_TESTING.md)
is still to run.

### Download

| File | What it is |
|---|---|
| `BudsBridge.exe` | Single file, no installer. Download and open it |
| `BudsBridge-0.3.1-windows-x64-setup.exe` | Installer for your user only: Start menu entry and uninstaller, no admin prompt |
| `SHA256SUMS.txt` | Checksums for both files |

The build isn't code-signed, so SmartScreen warns once: **More info → Run anyway**.

### Fixed

- **Opening a new version while an old one runs now switches to the new one.** Before, the old copy
  in the tray just came forward, so an update looked like it changed nothing.
- **Start with Windows** now always points at the copy you are running, not one you deleted.
- Releases are published as full releases, so they show on the repository page and at
  `releases/latest`.

### Updating from 0.3.0 or older

Those versions don't hand over yet: quit them first (right-click the tray icon → **Quit**), then open
the new `BudsBridge.exe`.

The tray dock and the new look for the dock and settings window, in light and dark.

**The dock.** BudsBridge now lives in the tray like a Mac menu bar app: click the tray icon and a
small panel opens beside it with everything you need day to day. The full window only opens for
settings.

This is a **pre-release**. Bridge mode has worked on a real Windows 11 laptop with an Android phone
and TWS buds; the rest of the
[hardware checklist](https://github.com/shakaibarsalan/BudsBridge/blob/main/docs/HARDWARE_TESTING.md)
is still to run.

### Download

| File | What it is |
|---|---|
| `BudsBridge.exe` | Single file, no installer. Download and open it |
| `BudsBridge-0.3.0-windows-x64-setup.exe` | Installer for your user only: Start menu entry and uninstaller, no admin prompt |
| `SHA256SUMS.txt` | Checksums for both files |

The build isn't code-signed, so SmartScreen warns once: **More info → Run anyway**.

### New

- **Tray dock**: a live picture of phone → laptop → buds, the number of sound sources in your buds,
  four tiles that are also the switches (buds, phone audio, hotkey, auto-reconnect), and the device and
  phone lists opening in place. It sits against the taskbar on any edge and closes when you click
  elsewhere.
- **A new look** for the dock and the settings window, after the InverterBar menu bar panel, in light
  and dark.
- The settings window opens from the dock (**All settings** or the gear) or the tray menu.
- Fixed: turning phone audio off now closes the stream before showing "Off".
- The Phone audio section explains that Windows shows paired phones as "Not connected" until you
  switch them on here.
